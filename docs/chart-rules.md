# 自动排盘的范围与取法

自动排盘由用户在应用首页开启，默认关闭；开关保存在本机。桌面小组件不读取此开关，也不调用排盘引擎。排盘使用信息页当前显示的日干支、月将和占时，支持历史时间和手动月将。

第一版显示天地盘、四课、三传、三传遁干与六亲。暂不排十二天将、神煞、本命行年，也不自动断课。这里的「月将」与「十二天将」不同。

## 依据

- [《六壬大全》卷一「起例」九宗门](https://zh.wikisource.org/zh-hant/六壬大全/1)：十干寄宫、贼克、比用、涉害、遥克、昴星、别责、八专、伏吟、返吟。
- [《六壬大全》卷七课经集一](https://zh.wikisource.org/zh-hant/六壬大全/7)：元首、重审、知一、涉害、遥克、昴星的原文课例已写入测试。
- [《六壬大全》别责课原文](https://www.shidianguji.com/book/SK1599/chapter/1k1lqkrmpxpgl)：丙辰日、辰将、卯时，三传亥午午；阴别责取支前三合本支。
- 古籍规则及课例属于传统规则资料；`ChartEngine.java` 为本项目独立实现，未复制其他排盘引擎的代码。研究时参考过公开实现，但没有把它们作为依赖或打包进应用。

## 本版固定口径

1. **天地盘**：月将加占时，十二支顺布。显示南在上，天盘大字、地盘小字。
2. **四课**：干寄宫上神为一课上神，第一课下神仍为日干本身；二课循干上神，三课支上，四课循支上。画面一课在右、四课在左。
3. **贼克**：先下贼上，后上克下；同一候选上神去重。有多个候选先按日干阴阳比用。
4. **涉害**：采用计深法，自候选所临地盘顺行归本家，计沿路地支及十干寄宫之克，不重复计当前所临宫，也不计归到本家后的克。下贼上计沿路受克，上克下计沿路所克；先取深者。深度相同再取孟、仲、季；同等阳日优先日课、阴日优先辰课。不是「直接取孟仲季、不计深」的简法。
5. **遥克**：无直接贼克，先神遥克日，再日遥克神，多候选取阴阳比用。八专无克不取遥克。
6. **昴星**：四课全、无克无遥，阳日取酉上，阴日取酉下；阳中支末干，阴中干末支。
7. **别责**：三课不备、无克无遥，阳取合干寄宫上神，阴取支前三合**本支**，中末均干上；不采用阴日再取三合支上神的另一取法。
8. **八专**：干支同宫无克，阳从干阳顺数三位，阴从支阴逆数三位，包含起点；中末均干上。
9. **伏吟**：有克先取克，无克阳干阴支；循刑取中末，初自刑换日辰，中自刑或回到初传取中冲。
10. **返吟**：有克依贼克、比用、涉害取发用，再按盘取中末；无克取支马、支上、干上。

各流派对于涉害和别责等有不同口径。本版只实现上述取法；「查看取传依据」会显示发用过程，方便人工复核。若用户提出另一流派需求，应作为明确选项新增，不应悄悄改变默认规则。

## 验证范围

- 独立指定24个课例（含卷七的10个原文课例），覆盖全部九宗门：阳/阴别责、阳/阴八专、有克/无克伏吟、自刑与子卯互刑、无克返吟。
- 穷举60日干支 × 12盘差，共720基本课，检查九宗门分支均可达、天地盘为十二支排列、四课与三传结构有效。
- 将月将和占时同步平移，扩展至8640组合法输入，检查同盘差结果不变。
- 普通传法检查初上为中、中上为末；与历法引擎的170项断言一同运行。
- 穷举和一致性检查证明程序在这些组合下的结构与不变量，不等于逐课与全部古籍课谱核对；手机运行与流派差异仍需使用者复核。
